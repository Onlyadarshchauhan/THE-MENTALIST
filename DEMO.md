# Two-minute demo script

Setup: open `index.html` in Chrome or Edge at 100% zoom. Have the 2023 report ready to open in a new tab (the links do this).

| Time | Show | Say |
|---|---|---|
| 0:00 | Action board | "Durga visarjan is in 9 days. This BMC officer decides where cleaning, aeration and testing go. The evidence sits in three MPPCB reports of nearly 300 pages, and nobody lines them up." |
| 0:15 | Click **32 of 37** | "First surprise: before a single idol went in, 32 of 37 BOD readings already failed the bathing limit. The problem is not only the festival, so action has to start before the day." |
| 0:35 | Matrix, top-right cell | "We rank on what was measured: oxygen below 4. Bairagarh comes first: below 4 in four of five events, zero four times. And it sits in the *gaps* column: the 2025 report has no Durga table for it. A latest-year dashboard would lose it." |
| 0:55 | Open Bairagarh, click **0 mg/l · Durga 2023 · p.60** | "Every number is checkable. This opens MPPCB's own report at page 60: D.Oxygen 0, 0." |
| 1:15 | Back, open Rani Kamlapati | "We show what we don't know. The Ganesh and Durga tables name this site differently; it may be two places, so we say 'confirm the site' instead of guessing. The new BMC ghats have no readings, and blank is not clean." |
| 1:35 | **Action plan** → हिन्दी → Copy | "One click gives the officer a forwardable plan in Hindi and English: where to act, which samples to request by when, including coliform, which was never tested, and what this data cannot tell us." |
| 1:55 | Banner | "Historical data, no live systems, no AI guesses. Every rank comes back to a reading and a page." |

Backup if the PDF viewer misbehaves: say "the page number is on the link", then open the report manually from `reports/` and go to page 60.
